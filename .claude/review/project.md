# Project checks (prefix P)

Checks only worklanes-trial needs, which the reviewer runs alongside the universal ones
(`universal.md`) and any stack checklists in this folder. Project-owned: the kit never changes this
file. Number new checks P1, P2, … and never reuse a retired number, so old review reports still
make sense.
