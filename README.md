# Reading list

A small reading-list tracker: an Express API (`server/`) and a plain HTML/JS front end
(`public/`). It is the two-lane trial of [parallanes](https://github.com/scotteskridge/parallanes),
built when the kit was still called claude-code-lanes-starter (so its command here is
`sh .claude/kit/kit`). The six tasks are the six commits after the install; the
[write-up](https://github.com/scotteskridge/parallanes/blob/main/docs/trial/two-lane-trial.md) has
the review findings.

```bash
npm ci
npm test
npm start
```

`PORT` picks the dev server's port (default 3000).
