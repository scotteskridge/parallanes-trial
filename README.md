# Reading list

A small reading-list tracker: an Express API (`server/`) and a plain HTML/JS front end
(`public/`). It exists as the two-lane trial project for
[claude-code-lanes-starter](https://github.com/scotteskridge/claude-code-lanes-starter).

```bash
npm ci
npm test
npm start
```

`PORT` picks the dev server's port (default 3000).
